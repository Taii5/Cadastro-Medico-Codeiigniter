CADASTRO DE MÉDICOS
********************

CodeIgniter 3.1.13 · PHP 5.6 · PostgreSQL

1- Apache + PHP 5.6 (com php5.6-pgsql) e PostgreSQL instalados.
2- Acessar http://localhost/project.5/
3-  Criei o banco `cadastro_medicos` e executar o script SQL das tabelas (`medicos`, `auditoria_medicos`).
4- Ajustar `application/config/database.php` (Dados de conexão com ProstgreSql) e `config.php` (base_url, language).
5- Tela de autentificação
6- Tela de login
7- Tela de cadastro caso não tenha um login
8- Tela da listagem de medicos
9- Tela do formulario para cadastrar um medico
10- Tela de Auditoria
11- Escolhi utilizar a opção de exclusão, pois, caso o médico deixe de trabalhar no hospital, seus dados não precisarão mais permanecer cadastrados no sistema.
