CADASTRO DE MÉDICOS
********************

CodeIgniter 3.1.13 · PHP 5.6 · PostgreSQL

1- Apache + PHP 5.6 (com php5.6-pgsql) e PostgreSQL instalados.
2- Acessar http://localhost/project.5/
3-  Criei o banco `cadastro_medicos` e executar o script SQL das tabelas (`medicos`, `auditoria_medicos`).
4- Ajustar `application/config/database.php` (Dados de conexão com ProstgreSql) e `config.php` (base_url, language).
5- Tela de login
6- Tela do cadstro de medicos no sistema 'application/views/medicos/listagem.php'
7- Tela para formulário 'application/views/medicos/formulario.php'
8- Escolhi utilizar a opção de exclusão, pois, caso o médico deixe de trabalhar no hospital, seus dados não precisarão mais permanecer cadastrados no sistema.
